## Deploy on Vercel

Use the **Next.js** framework preset, with `npm run build` as the build command
and the default output directory. The Next.js runtime handles direct requests
and reloads for `/`, `/my-plan`, and `/workouts/[id]`, as well as unknown routes.
Do not deploy this app as a static folder or add a catch-all rewrite to `/`.

For a Node.js host, run `npm run build` followed by `npm start`, and route all
requests to that server. Verify the deployment by opening and refreshing each
route directly, including `/workouts/1` and an unknown path such as `/missing`.

The easiest way to deploy your Next.js app is to use the [Vercel Platform](https://vercel.com/new?utm_medium=default-template&filter=next.js&utm_source=create-next-app&utm_campaign=create-next-app-readme) from the creators of Next.js.

Check out our [Next.js deployment documentation](https://nextjs.org/docs/app/building-your-application/deploying) for more details.
