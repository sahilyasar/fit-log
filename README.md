# FitLog

A simple workout library to explore exercises, plan your daily workouts, and save favorites for later.

## Technologies Used

- Next.js and React
- TypeScript
- Tailwind CSS and daisyUI
- React Toastify

## Key Features

1. **Workout library** — Browse exercises fetched from an API.
2. **Exercise details** — View instructions, muscle groups, equipment, and workout stats.
3. **Daily plan** — Add up to five exercises and track total minutes and calories.
4. **Saved workouts** — Save exercises for later and manage them from My Plan.
5. **Responsive experience** — Enjoy mobile-friendly layouts, loading animations, toast notifications, and a custom 404 page.
